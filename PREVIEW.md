# Тест многоязычной Лии

## Что готово для отдельного теста

Явный выбор девяти языков; меню на выбранном языке; диалоговое обучение,
ролевая тренировка, проверка знаний и свободный вопрос. Ответы используют
существующие три текстовые базы проекта. Числа и правила маркетинг-плана
не меняются вместе с языком. Кнопка источников работает на всех языках.

Смена языка сохраняет режим и историю в текущем процессе. После перезапуска
сохраняется только язык, если файл SQLite находится на постоянном диске.
История и результаты обучения пока не сохраняются постоянно.

Это отдельный прототип диалога, не готовая замена основного бота:
восемь фиксированных уроков и тестов, PDF, визитки и три шага приглашения
остаются в рабочей версии. Переводы меню требуют проверки носителями.
Реальный вызов OpenAI и Telegram в этой сессии не выполнялся.

## Запуск только в отдельном тестовом боте

Нужны пять настроек окружения, без сохранения значений в GitHub:

| Настройка | Назначение |
|---|---|
| `LIA_PREVIEW_TELEGRAM_TOKEN` | Токен отдельного тестового бота, не @Liya_Greenleaf_bot |
| `OPENAI_API_KEY` | Ключ проекта OpenAI |
| `LIA_PREVIEW_MODEL` | Проверенный доступный идентификатор модели для тестирования |
| `LIA_LANGUAGE_DB` | Абсолютный путь к SQLite на постоянном диске |
| `LIA_PREVIEW_ALLOWED_USER_IDS` | Telegram ID тестировщиков через запятую |

Доступность `gpt-5.6` из рабочего кода не проверялась, поэтому модель
прототипа задаётся явно. Никакая модель и никакой платный ресурс этой веткой
не включаются автоматически. Живой тест расходует баланс OpenAI API.

Запуск: `python -I /absolute/path/to/lia_preview.py`.

Флаг `-I` обязателен: он не даёт проектным sitecustomize/usercustomize
подключить перехваты основной Лии при старте прототипа. Рабочий запуск
`bot.py` и его зависимости не изменены. Прототип использует установленные
`python-telegram-bot==22.5` и OpenAI Python SDK (проверен импорт с 3.46.0).

## Приёмка

1. Войти тестировщиком: /start → язык → обучение → вопрос → ответ.
2. Начать проверку знаний, дать неверный ответ, проверить подсказку.
3. Переключить язык во время диалога через /language и продолжить тему.
4. Повторить для всех девяти языков; проверить uz в латинице и ввод кириллицей.
5. Убедиться, что два пользователя имеют независимые настройки.
6. Перезапустить тестовый процесс, убедиться в сохранении языка.
7. Проверить отсутствие обещаний дохода, сохранность PV/процентов/валюты,
   честный ответ при отсутствии данных и кнопку источников.

Автономные тесты не отправляют сообщения и не обращаются к OpenAI.
Запуск из любого каталога:

```sh
python -I -c 'import sys,unittest; sys.path.insert(0,"/absolute/path/to/repo"); suite=unittest.defaultTestLoader.discover("/absolute/path/to/repo/tests"); result=unittest.TextTestRunner(verbosity=2).run(suite); sys.exit(not result.wasSuccessful())'
```

Перед переносом в основную Лию нужно закончить локализацию всех фиксированных
сценариев и материалов, выбрать постоянное хранилище и согласовать публикацию.
